# MySQL 数据类型总结

MySQL 数据类型通常分为三大类：数值类型、日期时间类型和字符串类型。此外还有 JSON、空间类型、二进制类型等特殊类型。

## 1. 数值类型

### 整数类型
- `TINYINT[(M)] [UNSIGNED]`：1 字节，范围 -128~127，或 0~255。
- `SMALLINT[(M)] [UNSIGNED]`：2 字节，范围 -32768~32767，或 0~65535。
- `MEDIUMINT[(M)] [UNSIGNED]`：3 字节，范围 -8388608~8388607，或 0~16777215。
- `INT[(M)] [UNSIGNED]`：4 字节，范围 -2147483648~2147483647，或 0~4294967295。
- `BIGINT[(M)] [UNSIGNED]`：8 字节，范围 -2^63~2^63-1，或 0~2^64-1。

### 定点数和浮点数
- `DECIMAL(M,D)`：精确定点数，适合财务数据，M 为总位数，D 为小数位数。
- `FLOAT[(M,D)] [UNSIGNED]`：单精度浮点，近似值。
- `DOUBLE[(M,D)] [UNSIGNED]`：双精度浮点，近似值。

### 其他数值类型
- `BIT(M)`：位值，适合存储位掩码。
- `BOOL` / `BOOLEAN`：实际上是 `TINYINT(1)` 的别名。

## 2. 日期和时间类型
- `DATE`：仅日期，格式 `YYYY-MM-DD`。
- `TIME`：仅时间，格式 `HH:MM:SS`。
- `DATETIME[(fsp)]`：日期和时间，范围 `1000-01-01 00:00:00` 到 `9999-12-31 23:59:59`。
- `TIMESTAMP[(fsp)]`：日期时间，存储为 UTC，范围 `1970-01-01 00:00:01` 到 `2038-01-19 03:14:07`。
- `YEAR[(2|4)]`：年份，通常为 4 位。

## 3. 字符串类型

### 定长与变长字符串
- `CHAR(M)`：固定长度，最多 255 字节，适合长度固定的字符串。
- `VARCHAR(M)`：可变长度，最多 65535 字节，但受行长限制，适合一般文本。

### 文本类型
- `TINYTEXT`：最多 255 字节。
- `TEXT`：最多 65535 字节。
- `MEDIUMTEXT`：最多 16MB。
- `LONGTEXT`：最多 4GB。

### 二进制字符串
- `BINARY(M)`：固定长度二进制字符串。
- `VARBINARY(M)`：可变长度二进制字符串。
- `TINYBLOB` / `BLOB` / `MEDIUMBLOB` / `LONGBLOB`：二进制大对象，分别对应 255 字节、64KB、16MB、4GB。

## 4. JSON 类型
- `JSON`：用于存储 JSON 文档，MySQL 会自动验证 JSON 格式，并提供 JSON 函数查询和处理。

## 5. 空间类型（GIS/Geometry）
- `GEOMETRY`：通用空间对象。
- `POINT`、`LINESTRING`、`POLYGON` 等：用于存储地理空间数据。

## 6. 其他类型
- `ENUM('val1','val2',...)`：枚举类型，只能取预定义值之一。
- `SET('val1','val2',...)`：集合类型，可选择多个预定义值。

## 7. 常见使用建议
- 数值数据推荐使用 `INT` / `BIGINT`，金额使用 `DECIMAL`。
- 文本字段中，固定长度使用 `CHAR`，可变长度使用 `VARCHAR`。
- 长文本使用 `TEXT` 系列，而非 `VARCHAR`。
- 时间字段一般选 `DATETIME`，需要时区转换可使用 `TIMESTAMP`。
- 大量 JSON 数据使用 `JSON` 类型，便于查询和索引。
- 枚举值有限且固定时可使用 `ENUM`，但应谨慎避免业务扩展困难。

## 8. 注意事项
- MySQL 的 `UNSIGNED` 只能用于整数类型。
- `VARCHAR` 最大长度受行大小限制影响，不一定能达到定义的上限。
- `TIMESTAMP` 默认以 UTC 存储，在时区变化时更好使用。
- `TEXT` 和 `BLOB` 类型不能有默认值。
